# Job Monitor

A Python-based job monitoring bot that tracks career opportunities
across multiple company career pages.

## Initial Companies
- MongoDB
- Amazon

## Features
- Automated job monitoring
- Customisable job title filters
- Location-based filtering
- Duplicate job detection
- Telegram notifications

## Technology Stack
- Python
- Requests
- BeautifulSoup
- SQLite (planned)
- Telegram Bot API (planned)
